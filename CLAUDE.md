# Project rules

- Never use the brag skill or any video or recording tool. No web searches or image downloads unless I ask.
- The logo always stays in its original colours (red, black and white). Never recolour or redraw it.
- No "admin" role anywhere in the UI. The only roles are guest, staff and owner.
- Components call only `src/lib/api.ts` for data. Never touch storage or a backend directly.
- Do not change menu data, theme tokens or unrelated files unless I ask. Report the changed files at the end.
